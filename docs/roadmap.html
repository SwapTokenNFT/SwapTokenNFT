Roadmap

Детальная дорожная карта развития SwapToken-NFT от MVP до полноценной DAO.

Q2 2026 — Выполнено
Май — Июнь 2026
MVP Skeleton
Базовая структура репозитория, FastAPI backend с заглушками endpoint'ов, заготовка FunC-контракта для NFT-коллекции. Настройка CI/CD и линтеров.
BackendDevOps
Июнь 2026
Telegram Bot + TonConnect
Рабочий бот на aiogram с inline-кнопками, интеграция TonConnect для подключения кошелька, верификация подписи и nonce. Первая команда /mint для тестовой коллекции.
BotTonConnect

Агентная архитектура v1
Запуск Orchestrator с Redis ZSET очередями, регистрация 8 агентов. Circuit breaker для TON API и Telegram API. Event bus для межагентной коммуникации. FSM состояний пользователя.
AgentsRedisOrchestrator
Август — Сентябрь 2026
WebApp + SSO
Telegram WebApp с верификацией initData, мульти-кошелёк (до 5 адресов), переключение primary. Оптимистичный UI для минтинга.
WebAppSSO

Октябрь — Декабрь 2026
RWA Токенизация
Интеграция приватного блокчейна SwapToken (Satoshi). Мосты ликвидности между TON и SwapToken. Первые RWA-активы: недвижимость и commodities через оракулы.
RWABridgeOracle

GetGems + Blum Integration
Листинг коллекции на GetGems. Токен SWNF_P13io на Blum Memepad. Интеграция SDK для сторонних dApp.
MarketplaceToken
