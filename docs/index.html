Пользователь инициирует взаимодействие через Telegram-бота или веб-интерфейс. Система идентифицирует кошелёк TON и проверяет базовые права доступа.

  • Подключение TON-кошелька (TonConnect)
  • Верификация подписи и nonce
  • Определение роли: гость, держатель NFT, админ клуба
  • Роутинг на соответствующий сценарий

Многоуровневая проверка перед доступом к операциям с токенами и RWA-активами. Wallet Guard агент сканирует транзакции в реальном времени.

  • Проверка whitelist/blacklist адресов
  • Анализ рисков через AI Supervisor
  • Двухфакторная верификация критичных операций
  • Rate limiting и анти-фрод эвристики

Центральный Orchestrator управляет 8 агентами, распределяет задачи и обеспечивает согласованность состояний между TON-контрактом, backend и Telegram.

  • Маршрутизация intent-запросов к целевым агентам
  • Состояние FSM для каждой пользовательской сессии
  • Приоритизация: Marketing → Customer Success → Analytics
  • Синхронизация событий через event bus

Финальное выполнение операций: минтинг NFT, переводы SWNF, обновление метаданных RWA, взаимодействие с контрактом.

  • Генерация и подпись транзакций через SDK
  • Обновление IPFS-метаданных коллекции
  • Callback-уведомления в Telegram Bot
  • Запись аудит-лога для Compliance
