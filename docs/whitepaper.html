1. Резюме

SwapToken-NFT (SWNF) — это децентрализованная платформа для токенизации реальных активов (RWA) через NFT на блокчейне TON и приватном блокчейне SwapToken (Satoshi). Проект объединяет DeFi-инструменты, агентную автоматизацию и Telegram-интерфейс для создания доступной экосистемы цифровых активов.

Ключевые особенности: мульти-кошелёк с SSO через Telegram, 8 AI-агентов для оркестрации, circuit breaker для защиты внешних API, приоритетные очереди задач и полная интеграция с TON-экосистемой.

2. Проблема и решение

2.1 Проблема

Традиционные NFT-проекты страдают от фрагментации: отдельные маркетплейсы, сложные интерфейсы, отсутствие связи с реальными активами и высокий порог входа для не-технических пользователей.

2.2 Решение

  • Telegram как единый вход — миллиарды пользователей уже имеют аккаунт
  • RWA-токенизация — каждый NFT обеспечен реальным активом через оракулы
  • Агентная автоматизация — AI-агенты выполняют рутину: маркетинг, поддержку, аналитику
  • Двухцепочечная архитектура — TON для публичных операций, SwapToken для институциональных

Система построена по принципу микросервисной агентной сети. Каждый агент — изолированный процесс с чётко определённым API, взаимодействующий через Redis Event Bus и gRPC.

4. Агентная сеть

8 специализированных агентов работают под управлением Orchestrator с приоритетными очередями (Redis ZSET) и защитой circuit breaker:

  • Orchestrator (CRITICAL) — маршрутизация задач, FSM состояний, circuit breaker registry
  • Wallet Guard (CRITICAL) — сканирование адресов, whitelist/blacklist, риск-скоринг
  • AI Supervisor (HIGH) — мониторинг здоровья, алертинг, метрики
  • Marketing (NORMAL) — кампании, сегментация, A/B тесты
  • Strategic Growth (NORMAL) — аналитика роста, прогнозирование
  • Customer Success (LOW) — поддержка, onboarding, тикеты
  • Club Agent (LOW) — управление доступами, роли, верификация
  • Club Economy (LOW) — рефералы, staking, динамическое ценообразование

5. Токеномика SWNF

Общий supply: 1 000 000 000 SWNF. Распределение:

  • Community Rewards (20%) — airdrop, staking, участие в экосистеме
  • Liquidity & DEX (15%) — пулы ликвидности, маркет-мейкинг
  • Team & Advisors (15%) — 2-летний vesting с cliff 6 месяцев
  • Treasury (20%) — развитие проекта, гранты, партнёрства
  • RWA Reserve (20%) — обеспечение реальными активами
  • Marketing (10%) — кампании, инфлюенсеры, events

6. Модель безопасности

Многоуровневая защита на всех этапах:

  • Уровень 1 — SSO — верификация Telegram initData через HMAC-SHA256
  • Уровень 2 — TonConnect Proof — подпись nonce для подтверждения владения кошельком
  • Уровень 3 — Circuit Breaker — автоматическое отключение при сбоях TON API / Telegram API
  • Уровень 4 — AI Supervisor — аномалии в паттернах транзакций, проактивный алертинг
  • Уровень 5 — On-chain Audit — все операции записываются в аудит-лог для Compliance

7. Управление и DAO

Постепенный переход к DAO-управлению в 3 этапа:

  • Этап 1 (Q3 2026) — совет из держателей NFT, голосование за улучшения
  • Этап 2 (Q2 2027) — Snapshot голосование по параметрам токеномики
  • Этап 3 (Q4 2027) — полный DAO с мультиподписью и делегированием
