О проекте SwapToken-NFT

NFT / DeFi-проект на TON и приватном блокчейне SwapToken (Satoshi). Токенизация реальных активов (RWA).

Миссия

SwapToken-NFT объединяет мир NFT и децентрализованных финансов на базе TON-экосистемы. Мы создаём инфраструктуру для токенизации реальных активов (RWA) через NFT-коллекции, обеспечивая прозрачность, ликвидность и доступность для каждого держателя.

Проект работает на двух блокчейнах одновременно: публичный TON для широкой аудитории и приватный блокчейн SwapToken (Satoshi) для институциональных операций и межсетевых мостов.

Технологии

  • TON (The Open Network) — основная сеть для NFT, DeFi и пользовательских операций
  • SwapToken Blockchain (Satoshi) — приватный блокчейн для RWA и институциональных транзакций
  • FunC — язык смарт-контрактов для TON
  • FastAPI + Python — backend с 8 агентами автоматизации
  • Telegram Bot + WebApp — основной интерфейс пользователя
  • IPFS — децентрализованное хранение метаданных NFT
